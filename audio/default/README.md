`seed.wav` is an original, ten-second mono harmonic sound created for this project. It uses 220 Hz and 330 Hz sine waves and a gentle amplitude envelope, at 24 kHz / 16-bit PCM. No participant recording or external sample is used.

Source description: Soft sustained harmonic tones with a gentle pulse. An instrumental soundscape. No speech.
